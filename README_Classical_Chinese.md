# 極簡播放器

> 單文一冊，不假外物，盡在本地之網頁音視頻播放器。凡解碼與播映，皆成於瀏覽器之內，**未嘗上傳分毫**。

## 速覽入門

1. 徑以瀏覽器開 `index.html`（連點兩下即可，無須起服務器、無須構建、不賴網絡）。
2. 將音視頻之文件**拖入播放之區**，或點右上「＋選擇文件」。
3. 播映與暫停：點播放之鈕，或點視頻之畫面。

> 惟拖至**播放之區**，方能載入文件；拖於頁面他處則不載入，亦不令瀏覽器徑開該文件而奪此頁。

## 功能總覽

| 功能 | 釋義 |
| --- | --- |
| 播映／暫停 | 播放之鈕，或點視頻畫面；圖標微有伸縮之應 |
| 波形＋跳轉 | 示音軌之波形與播映之進度；**點波形任意處即可跳轉**（波形之區即頁上唯一之進度條） |
| 實時頻譜 | 音頻文件於播放之區示實時柱狀頻譜；暫停或空閒時，退為靜態低幅之波形 |
| 倍速 | 0.5× ／ 0.75× ／ 1.0× ／ 1.25× ／ 1.5× ／ 2.0× ／ 3.0×，易文件後仍存 |
| 音量／靜音 | 音量自 0 至 1；靜音則收音量條與增強之組，點喇叭即復 |
| 音量增強 | 1.0× 至 10.0× 之增益，後接削峰限制器（可獨自關之） |
| 全屏 | 放大播放之區至全屏，按 Esc 退出 |
| 拖拽載入 | 拖至播放之區即載入，有虛線高亮之應 |

## 所容之格式

- **視頻**：MP4 / M4V / WebM / MOV / MKV / AVI / FLV / WMV / MPEG / TS / 3GP / OGV / RMVB / VOB
- **音頻**：MP3 / WAV / FLAC / M4A / AAC / OGG / OPUS / WMA / AIFF / ALAC / APE

> 終能播否，繫於**瀏覽器**解碼之力。上列 MKV / AVI / RMVB 諸封裝，Chrome / Edge 多不能解——遇此則明示其由，不至徒留黑屏。

## 實現之要

1. **單文零依**：CSS 與原生 JS 盡行內聯，絕無外求，可徑離線而用。
2. **文件類型之辨**：先察 MIME；瀏覽器不與 MIME（如 `.mkv`）者，則退而察其擴展之名，否則視頻將誤為音頻而隱其畫。
3. **波形乃異步解碼而得**，故：
   - 以遞增之 `loadToken` 廢在途之解碼結果，免舊文件之波形掩新文件；
   - 解碼所用之 `AudioContext` 必於 `finally` 中關閉，免積累至不復能建；
   - **設有閘門**：文件逾 256MB，或時長逾三十分，逕捨整軌之解碼。整軌解碼之 PCM 隨時長而線性增長（一時辰立體聲 48k 約 1.3GB），實測一三十四分鐘／530MB 之視頻，`decodeAudioData` 奔七十五秒而不返，且將全文件納於內存。捨之則波形區退為常進度條，**仍可點而跳轉**。
4. **音量**：徑用 `video.volume` / `video.muted`（實測接入 Web Audio 後二者猶存），增益之節惟司「增強」，不復衰減。
5. **限制器**默開，閾值 −1dB、壓縮比 20:1，惟削其峰，不壓正常之音。
6. **頻譜**：`fftSize = 256`（百二十八頻點），升疾而落緩，以避抖動。
7. **HiDPI**：canvas 之尺寸按 `dpr` **取整而後**相比。若以 `clientWidth * dpr` 之浮點相比，則於 125%／150% 此類非整之縮放下永不相等，遂成每幀重設畫布（重配且復清）——實測 dpr=1.25 時每秒重設五十九次，修後為零。

## 已知之態（有意為之，非缺陷也）

- **跳轉後界面微有遲滯**：點波形之後，時刻之數與進度之條，須俟瀏覽器 seek 既畢乃新，大文件或遲數百毫秒（瀏覽器之性，未作樂觀之更，以免與真畫相違）。
- **靜音則音量條與增強之組收起**：惟存喇叭之鈕，一點即復。
- **全屏惟放大播放之區**，控制之條不在全屏之內，用 Esc 退出。
- **超長／超大之媒體無波形**：見前閘門之說，此時波形區為一靜態之刻度，點之仍可跳轉。
- 無鍵盤之快捷（空格播放／暫停之類），亦無內置之播放列表。

## 本次修復之記

於早期一版作全審（以無頭 Edge 加 CDP 真機實測，遍及音頻／視頻／無音軌／損壞文件／超長視頻／多種視口與縮放比），凡修九處：

| 序 | 問題 | 現象 |
| --- | --- | --- |
| 一 | `body` 用 flex 居中且 `height:100%` | 內容高於視口時，溢出之部被推至視口之上且**無從滾至**，矮窗之下品牌與「選擇文件」之鈕盡不可及。改為 `.app{margin:auto}` |
| 二 | 波形進度誤以秒數為比例 | 解碼既畢時若已播逾一秒，整條波形被畫作「已播」，暫停時猶續其誤 |
| 三 | 文件輸入未清 `value` | 再選**同一文件**不發 `change`，界面毫無所應 |
| 四 | 播放中易文件後圖標不齊 | `video.load()` 不發 `pause`，鈕停於「暫停」之圖而實已暫停 |
| 五 | 波形區於無峰值時不可跳轉 | 波形區乃惟一之進度條；無音軌之視頻、超長之視頻遂**全不可跳轉** |
| 六 | 超長媒體整軌解碼而滯 | 三十四分鐘／530MB 之視頻，解碼七十五秒不返，波形終不可出且占數百 MB 內存 |
| 七 | 不支持之格式惟餘黑屏 | 初無一示；今復用空態之層，示其由與所宜之格式 |
| 八 | 進度高亮於 0% 時點亮首柱 | 比較之 `i/n` 改為 `(i+1)/n`（柱 i 覆 `[i/n, (i+1)/n]`） |
| 九 | HiDPI 下每幀重設畫布之尺寸 | dpr 非整時每秒重設五十九次（重配且復清），取整相比後為零 |

## 瀏覽器之相容

Chrome / Edge / Firefox / Safari 之近世諸版。所用皆標準之 API：`<video>`、Canvas 2D、Web Audio（`AnalyserNode` / `GainNode` / `DynamicsCompressorNode`）、`Fullscreen API`、`URL.createObjectURL`、`File.arrayBuffer`。
