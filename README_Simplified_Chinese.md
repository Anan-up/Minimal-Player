这是一个**完全自包含的本地媒体播放器**（HTML + CSS + JS），无需任何外部依赖，所有数据仅在浏览器本地处理，强调隐私与极简交互。

---

### 1. 核心定位与交互
- **双模式支持**：自动区分**视频**（MP4/WebM/MOV）与**音频**（MP3/WAV/FLAC/M4A）。
- **加载方式**：支持**点击选择**文件或**拖拽**文件至播放舞台区域。
- **隐私安全**：使用 `URL.createObjectURL` 生成本地临时链接，文件不会上传至任何服务器。

### 2. 播放控制体系
- **基础控制**：播放/暂停（点击按钮或视频画面）、进度拖拽（点击波形条跳转）、音量调节与静音。
- **高级控制**：**倍速播放**（0.5倍至3.0倍）、**全屏模式**（适配视频/音频舞台）。
- **状态反馈**：顶部显示文件名与格式标签，底部实时更新播放时间。

### 3. 音频可视化（技术亮点）
该播放器针对音频模式提供了**两套独立的视觉反馈机制**：

- **底部波形图（概览与跳转）**：
  - 利用 `AudioContext` 解码音频数据，计算峰值（`computePeaks`）并绘制为柱状波形。
  - **可交互**：点击波形任意位置，可直接跳转到对应的播放进度（`video.currentTime`）。
  - 播放过程中，波形图会根据当前进度高亮已播放部分（灰色变黑色）。

- **舞台中央频谱图（实时动态）**：
  - 音频播放时，舞台区域隐藏视频元素并显示 `canvas`。
  - 使用 **`AnalyserNode`** 实时获取频域数据（FFT），绘制为动态柱状频谱。
  - 音频暂停或结束时，频谱图自动回落为静态低幅装饰波形，保证界面始终不空旷。

### 4. 关键技术架构细节
- **Web Audio API 延迟初始化**：`ensureAudioGraph` 方法在首次播放音频时才创建 `AudioContext`，规避了浏览器的自动播放策略限制，且 `MediaElementSource` 仅连接一次防止报错。
- **高清适配渲染**：所有 Canvas 绘图均乘以 `devicePixelRatio`，确保在 Retina 屏幕上清晰显示。
- **事件驱动设计**：严格监听 `play`/`pause`/`ended`/`timeupdate` 事件，实现 UI 状态（按钮图标、频谱开关、波形进度）的精准联动。

### 5. 视觉与体验风格
- **极简主义**：浅色背景、细边框、大圆角，去除了冗余装饰。
- **交互反馈**：悬停变色、点击动效、拖拽高亮边框，操作手感流畅自然。
