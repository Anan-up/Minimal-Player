这是一个功能完备、设计简洁的**本地媒体播放器** HTML 应用，全部在浏览器端运行，无需后端服务。

---

## 1. 整体架构与技术栈
- **纯前端**：单页 HTML，内嵌 CSS 和 JavaScript，无外部依赖。
- **媒体处理**：利用 `<video>` 和 Web Audio API 实现播放、实时音频分析和增益控制。
- **渲染与动画**：使用 Canvas 绘制波形图和柱状频谱，通过 `requestAnimationFrame` 驱动实时可视化。
- **响应式设计**：移动端适配，采用 `aspect-ratio` 和弹性布局。

---

## 2. 核心功能
- **本地文件加载**  
  - 支持点击“选择文件”或拖拽文件到播放区域。  
  - 自动识别视频（MP4、WebM、MOV）和音频（MP3、WAV、FLAC、M4A）。  
  - 文件仅在本地处理，不会上传服务器。
- **播放控制**  
  - 播放 / 暂停（点击中央区域或按钮）。  
  - 进度显示（当前时间 / 总时长）。  
  - 进度跳转：点击波形图任意位置可定位到对应时间点。
- **音量管理**  
  - 滑块调节音量（0~1）。  
  - 一键静音，静音时自动隐藏音量滑块和增强控件（提升 UI 简洁性）。
- **播放速度**  
  - 预设速度档位：0.5×、0.75×、1.0×、1.25×、1.5×、2.0×、3.0×。  
  - 点击按钮弹出选择菜单，点击外部自动关闭。
- **全屏模式**  
  - 支持视频全屏播放（舞台区域全屏），全屏时隐藏圆角、调整宽高比。

---

## 3. 用户交互体验
- **视觉反馈**  
  - 拖拽时显示虚线边框提示。  
  - 播放按钮点击伴有缩放动画（`pop` 关键帧）。  
  - 状态切换（播放/暂停、增强开关、限制器开关）通过按钮样式变化（`on` 类）和图标区分。
- **控件分组与折叠**  
  - “音量增强”面板默认折叠，点击增强开关展开，内部包含倍率滑块（1~10 倍）和限制器开关。  
  - 面板展开/收起有平滑的 `max-height` 过渡动画。
- **无障碍**：使用语义化标签，输入控件配有 `title` 提示。

---

## 4. 可视化组件
### （1）音频波形图（`#wave` Canvas）
- **计算**：加载文件后，通过 `AudioContext.decodeAudioData` 解码音频，提取左声道峰值数据（160 个采样点），归一化后存储为 `peaks`。
- **绘制**：采用圆角矩形条，已播放部分（相对于当前播放进度）填充深色，未播放部分浅灰色，直观显示播放位置。
- **交互**：点击波形图可跳转至对应时间点。

### （2）实时频谱（`#spectrum` Canvas）
- **触发**：仅在**音频文件**播放时激活（视频文件不显示频谱，仅显示视频画面）。
- **数据源**：通过 `AnalyserNode` 获取频域数据（FFT size = 256，共 128 个频点）。
- **绘制逻辑**：  
  - 使用平滑算法（上升快、回落慢）抑制抖动，生成稳定柱状图。  
  - 播放时实时更新，暂停或结束时回退为静态低幅模拟波形。
- **性能**：由 `requestAnimationFrame` 驱动，空闲时取消循环以节省资源。

---

## 5. 音频处理（增益与限制器）
为支持音量增强（最高 10 倍）并防止削波失真，构建了完整的音频处理链：
```
MediaElementSource → GainNode → DynamicsCompressor (限制器) → AnalyserNode → AudioContext.destination
```
- **增益节点**（`gainNode`）：根据 `boostOn` 状态和 `boost` 滑块值动态调整增益（默认关闭时增益为 1）。
- **限制器**（`DynamicsCompressor`）：阈值 -6 dB，压缩比 20:1，软拐点 0，起/释时间 3 ms / 250 ms，有效防止大信号过载。
- **旁路支持**：限制器可开关，关闭时增益节点直接连接分析器，满足不同用户偏好。
- **应用时机**：音频上下文在首次播放时延迟初始化（`ensureAudioGraph`），确保兼容性且不浪费资源。

---

## 6. 其他细节
- **错误容忍**：音频解码失败（如某些视频容器）时，波形图不显示，但播放不受影响。
- **自适应重绘**：窗口缩放时自动调整 Canvas 尺寸（考虑 `devicePixelRatio` 保证清晰度）。
- **全屏适配**：全屏时去除圆角边框，视频画面铺满舞台。
- **文件信息展示**：显示文件名、类型（视频/音频）和格式后缀。
