# 极简播放器 / Minimal Player

单文件、零依赖、纯本地的网页音视频播放器。所有解码与播放都在浏览器里完成，**不上传任何数据**。

```
player/
└── index.html      # 整个播放器（HTML + CSS + 原生 JS，710 行，无外部资源）
```

## 快速开始

1. 直接用浏览器打开 `index.html`（双击即可，不需要起服务器、不需要构建、不依赖网络）。
2. 把音视频文件**拖进播放区**，或点右上角「+ 选择文件」。
3. 播放/暂停：点播放按钮，或点视频画面。

> 只有拖到**播放区**才会载入文件；拖到页面其它地方不会载入，同时也不会让浏览器直接打开该文件把页面顶掉。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 播放 / 暂停 | 播放按钮或点击视频画面；图标带轻微缩放反馈 |
| 波形 + 跳转 | 显示音轨波形和播放进度；**点击波形任意位置即可跳转**（波形区就是页面上唯一的进度条） |
| 实时频谱 | 音频文件在播放区显示实时柱状频谱；暂停/空闲时回落为静态低幅波形 |
| 倍速 | 0.5× / 0.75× / 1.0× / 1.25× / 1.5× / 2.0× / 3.0×，换文件后保持 |
| 音量 / 静音 | 音量 0–1；静音时收起音量条与增强组，点喇叭恢复 |
| 音量增强 | 1.0×–10.0× 增益，后接削峰限制器（可单独关掉） |
| 全屏 | 把播放区放大到全屏，Esc 退出 |
| 拖拽载入 | 拖到播放区即载入，带虚线高亮反馈 |

## 支持的格式

- **视频**：MP4 / M4V / WebM / MOV / MKV / AVI / FLV / WMV / MPEG / TS / 3GP / OGV / RMVB / VOB
- **音频**：MP3 / WAV / FLAC / M4A / AAC / OGG / OPUS / WMA / AIFF / ALAC / APE

> 最终能不能播，取决于**浏览器**的解码能力。上面列表里的 MKV / AVI / RMVB 等封装，Chrome / Edge 通常解不开——这种情况会给出明确提示，而不是留一块黑屏。

## 实现要点

1. **单文件零依赖**：CSS 与原生 JS 全部内联，没有任何外部请求，可直接离线使用。
2. **文件类型识别**：优先看 MIME；浏览器给不出 MIME（如 `.mkv`）时回退到扩展名判断，否则视频会被当成音频而隐藏画面。
3. **波形是异步解码出来的**，因此：
   - 用递增的 `loadToken` 作废在途的解码结果，避免旧文件的波形盖掉新文件；
   - 解码用的 `AudioContext` 在 `finally` 里必定关闭，避免累积到无法再新建；
   - **有闸门**：文件 > 256MB，或时长 > 30 分钟，直接跳过整轨解码。整轨解码的 PCM 体量随时长线性上涨（1 小时立体声 48k ≈ 1.3GB），实测一个 34 分钟 / 530MB 的视频 `decodeAudioData` 跑 75 秒都没返回，还会把整个文件读进内存。跳过后波形区退化为普通进度条，**仍然可以点击跳转**。
4. **音量**：直接使用 `video.volume` / `video.muted`（实测接入 Web Audio 后二者依然生效），增益节点只负责「增强」，不做二次衰减。
5. **限制器**默认开启，阈值 −1dB、压缩比 20:1，只削峰不压正常音量。
6. **频谱**：`fftSize = 256`（128 个频点），上升快、回落慢，避免抖动。
7. **HiDPI**：canvas 尺寸按 `dpr` **取整后**再比较。若拿 `clientWidth * dpr` 的浮点值比较，在 125% / 150% 这类非整数缩放下永远不相等，会变成每帧重设一次画布（重新分配 + 清空）——实测 dpr=1.25 时每秒重设 59 次，修复后为 0 次。

## 已知行为（有意为之，不是 bug）

- **跳转后界面有轻微延迟**：点击波形后，时间数字和进度条要等浏览器 seek 完成才刷新，大文件可能有几百毫秒延迟（浏览器行为，未做乐观更新以免与真实画面不一致）。
- **静音时音量条和增强组会收起**：只保留喇叭按钮，点一下即恢复。
- **全屏只放大播放区**，控制条不在全屏范围内，用 Esc 退出。
- **超长/超大媒体没有波形**：见上文闸门说明，此时波形区是一条静态刻度，点击仍可跳转。
- 没有键盘快捷键（空格播放/暂停等），也没有内置播放列表。

## 本次修复记录

对一个早期版本做完整审查（用无头 Edge + CDP 真机实测，覆盖音频/视频/无音轨/损坏文件/超长视频/多种视口与缩放比），共修复 9 处：

| # | 问题 | 现象 |
| --- | --- | --- |
| 1 | `body` 用 flex 居中且 `height:100%` | 内容高于视口时，溢出部分被推到视口上方且**无法滚动到**，矮窗口下品牌和「选择文件」按钮彻底不可达。改为 `.app{margin:auto}` |
| 2 | 波形进度传了秒数当比例 | 解码完成时若已播过 1 秒以上，整条波形被画成「已播放」，暂停时还会一直错下去 |
| 3 | 文件输入未清空 `value` | 再次选择**同一个文件**不会触发 `change`，界面毫无反应 |
| 4 | 播放中换文件后图标不同步 | `video.load()` 不触发 `pause`，按钮停在「暂停」图标而实际已暂停 |
| 5 | 波形区在无峰值时不能跳转 | 波形区是唯一的进度条；无音轨视频、超长视频因此**完全无法跳转** |
| 6 | 超长媒体整轨解码卡死 | 34 分钟 / 530MB 的视频解码 75 秒不返回，波形永远出不来且占用数百 MB 内存 |
| 7 | 不支持的格式只剩黑屏 | 无任何提示；现在复用空状态层显示原因和建议格式 |
| 8 | 进度高亮在 0% 时点亮第一根柱 | 比较用 `i/n` 改为 `(i+1)/n`（柱子 i 覆盖 `[i/n, (i+1)/n]`） |
| 9 | HiDPI 下每帧重设画布尺寸 | dpr 非整数时每秒重设 59 次（重新分配 + 清空），取整比较后为 0 次 |

## 浏览器兼容

Chrome / Edge / Firefox / Safari 的现代版本。用到的都是标准 API：`<video>`、Canvas 2D、Web Audio（`AnalyserNode` / `GainNode` / `DynamicsCompressorNode`）、`Fullscreen API`、`URL.createObjectURL`、`File.arrayBuffer`。
